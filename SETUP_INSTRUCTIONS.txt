ADMIN ACCOUNT SETUP - CONFIDENTIAL
================================================================================

STEP 1: Go to Login Page
- Open your application at: /login

STEP 2: Initialize Admin Account (Browser Console)
- Press F12 to open Developer Tools
- Go to the Console tab
- Copy and paste this command:

import { setupAdmin } from '@/utils/setupAdmin'
await setupAdmin('umair@aviratechnologies.com', '123456', 'Umair')

- Press Enter to execute
- Wait for the success message

STEP 3: Login
- Go back to login page
- Enter email: umair@aviratechnologies.com
- Enter password: 123456
- Click Sign In

STEP 4: Change Default Password (IMPORTANT!)
- After logging in, click Settings button (top right)
- Go to "Profile Settings" tab
- In "Change Password" section:
  * Current Password: 123456
  * New Password: (choose a strong password)
  * Confirm Password: (repeat the new password)
  * Click "Change Password"

STEP 5: Manage Users
- Go to Settings → "Manage Users" tab
- Add new users with:
  * Email address (must be unique)
  * Full name
  * Password (minimum 6 characters)
  * Confirm password
- Click "Add User"
